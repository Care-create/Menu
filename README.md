# Menu - Menüdatenbank Hotel Hohenlohe

Eine Webapp zur Verwaltung und Planung von Menükarten.

## Struktur

```
Menu/
├── backend/     # Node.js + Express API
├── frontend/    # React Webapp
└── import/      # Skript zum Einlesen der Word-Dateien
```

## Funktionen

- Gerichte aus ~2000 Menükarten importieren
- Kategorisierung: Vorspeise, Suppe, Hauptgang, Beilage, Dessert
- Saisonale Zuordnung (Frühling, Sommer, Herbst, Winter)
- Eigene Menüs zusammenstellen
- Wochenplan automatisch vorschlagen
- Login für bis zu 10 Benutzer
